| Time | Step | On screen |
|---|---|---|

## How it maps to what we already have

- Higgsfield is connected to Claude. Its explainer styles are the same "trending style" cards: 22 vertical (9:16) presets, including Low Poly (the look of the example result), Colorful 3D, Pixel Art, Claymotion, Paper Diorama, Stickman Cartoon, Whiteboard Doodle, Isometric Flat Vector and Studio 3D.
- The connector also has a "faceless-video" workflow (narrated explainer, history, kids, picture story, fairy tale and myth). That is the "Generate in Claude" path, so Claude can make these without the website.
- Metricool already posts to the YouTube channel (brand 7513806), so the posting step is in place. Facebook and TikTok would need to be connected in Metricool.
- The current daily pipeline makes about 57-second code-built Shorts. A 2-minute version would clear TikTok's 1-minute rule, and it can still post to YouTube as a Short: Shorts can run up to 3 minutes since October 2024 ([PetaPixel](https://petapixel.com/2024/10/04/youtube-shorts-expands-video-length-to-three-minutes/), [Social Media Today](https://www.socialmediatoday.com/news/youtube-expands-3-minute-shorts-to-all-users/736967/)).

## What we need before starting

- Higgsfield credits: the account was on the free plan with about 4 credits on 2026-11-09; one 3-episode, 2-minute run shows about 378 credits.
- A topic list: the prompt needs a [TOPIC]; the playbook already bans repeat topics and asks for sourced numbers.
- Decide whether these replace or sit alongside the code-built Shorts, and which platforms get them.
- Originality: use a viral video as inspiration only (as the prompt says). YouTube does not monetize reused or mass-produced, templated content, so each video needs its own script and visuals.
